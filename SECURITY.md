# Security policy

## Scope

This policy covers the static site and its JavaScript. Tax or legal accuracy questions belong in normal issues. Third-party browsers are outside this project's scope.

## Reporting a vulnerability

Use **Report a vulnerability** in this repository's GitHub Security advisories to send a private vulnerability report. Do not post real personal data, PANs or receipts in public issues. Use fake data when demonstrating a problem.

Include steps to reproduce, your browser and version, and the possible impact.

Reports receive a best-effort response. There is no guaranteed response or fix timeline.

## Privacy design

The app has no backend, stores no form data and makes no third-party requests. Most issues would be client-side, such as cross-site scripting (XSS), unsafe links or print output exposing unintended details.
